# create-amphion

Scaffold a new [Amphion](https://github.com/amphionjs/amphion) app. Amphion is a TypeScript-first Node.js framework with the developer experience of Laravel.

```bash
npm create amphion@latest my-app
```

This creates a `my-app` folder with the Amphion project structure (`app/`, `config/`, `database/`, `routes/` and more).

> **Status: pre-alpha.** The framework packages (`@amphion/*`) arrive with v0.1. Until then, this installer creates the project structure only.
