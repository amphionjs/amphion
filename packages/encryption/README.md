# @amphion/encryption

AES-256-GCM encrypter and signed values (HMAC message verifier) with key rotation.

Part of [Amphion](https://github.com/amphionjs/amphion), a TypeScript-first Node.js framework with the developer experience of Laravel.

> **Status: scaffold only.** Planned for Phase 5 (security, sessions and auth).
