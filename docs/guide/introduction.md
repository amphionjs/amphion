# Introduction

Amphion is a TypeScript-first Node.js framework with the developer experience of Laravel: a service container, service providers, an Eloquent-style ORM, Artisan-style commands (the `lyre` CLI), queues, events, mail and more.

::: warning Pre-alpha
Amphion is in early development. None of the framework packages are released yet, and the APIs in the README are the target design. The first usable release (v0.1: core kernel, HTTP layer and CLI) is planned for week 15 of the roadmap.
:::

## Requirements

- Node.js 24 LTS or newer
- pnpm, npm or yarn
